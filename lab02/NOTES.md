1)Рабочая папка - это папка с файлами проекта

2)Инедкс - это место где через git add, мы закидываем то что пойдет в следующий commit.

3)Коммит - это у нас точка сохранения проекта с автором и описанием, и к ней можно всегда вернуться



&#x09;		2

Git- это программа на пк

GitHub - сайт, где этот репозиторий лежит, с помощью этого можно делиться кодом с другими юзерами.



&#x09;		3

git diff - смотрит разницу между файлами на диске и тем, что закинули в индекс.

git diff --staged - показывает что уже в индексе и последним коммитом.



&#x09;		4

git status - выводит текущее состояние

git diff - различие между индекса и последним коммитом

git diff --staged - показывает последние изменения относительно последнего commit



&#x09;		5

5\) Ветки:

Ветка — это отдельная лини работы с кодом, чтобы не ломать главный код.

Когда делаешь новый коммит, ветка сама двигается вперед вместе с ним.

Слияние  — соединяет изменения из другой ветки обратно в main.
